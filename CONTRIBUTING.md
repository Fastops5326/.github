# You are in a Fastops5326 repo

This file is served org-wide from
[`Fastops5326/.github`](https://github.com/Fastops5326/.github). It is a
pointer, not a policy document. The docs of record live in
[`Fastops5326/fastops-pipeline`](https://github.com/Fastops5326/fastops-pipeline),
versioned and PR-gated. Read them there; never paste them into a repo.

- **What you may do — credentials, gates, the break-glass rail:**
  [`docs/AGENT-ACCESS.md`](https://github.com/Fastops5326/fastops-pipeline/blob/main/docs/AGENT-ACCESS.md)
- **How to send findings, feedback, or requests to the pipeline:**
  [`docs/AGENT-INTAKE.md`](https://github.com/Fastops5326/fastops-pipeline/blob/main/docs/AGENT-INTAKE.md)
  — commit your full write-up in your own repo, stage one rollup per
  report at `intake/outbox/<report-id>.md` on your default branch, and
  stop. The pipeline pulls daily and mirrors it home as an issue. You
  need zero access to the pipeline repo to be heard.

If a repo needs instructions of its own, they belong in that repo's
files. This one stays a pointer.
